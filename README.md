# Magnumja's Homebrew tap

```bash
brew install --cask magnumja/tap/notchuser
```

| Cask | App |
| --- | --- |
| `notchuser` | [NotchUser](https://github.com/Magnumja/NotchUser): a Dynamic Island for your MacBook's notch, with music, synced lyrics, a file shelf, and live activities for Claude Code, Codex and Copilot. |

Update with `brew upgrade --cask notchuser`, remove with `brew uninstall --cask notchuser` (add `--zap` to also delete its settings and caches).

NotchUser isn't notarized by Apple, so the cask removes the download quarantine flag after installing, the same thing the app's README asks you to do by hand.
